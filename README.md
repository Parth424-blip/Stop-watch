# Stop-watch
Stopwatch Web App
A simple and responsive stopwatch web application built using HTML, CSS, and JavaScript. This project allows users to start, stop, and reset the timer with ease.

🔧 Features
Start, Stop, and Reset functionality

Accurate time tracking in hours, minutes, seconds, and milliseconds

Responsive and clean UI

Built with only vanilla HTML, CSS, and JS 

Technologies Used
HTML – Structure of the app

CSS – Styling and layout

JavaScript – Core logic for stopwatch functionality
